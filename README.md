# Project 22: Hospital Management System (Aegis Health)

A clinical operations and hospital management platform built with React, Vite, TailwindCSS, and Zustand.

## Features
- **Calm Blue-White Clinical Theme**: High-contrast, clutter-free clinical layout with Inter and JetBrains Mono typography.
- **Inpatient Admissions & Discharge**: Real-time registry tracking patient intake, bed/ward allocation, and discharge settlements.
- **Wards & Beds Resource Matrix**: Live tracking of ICU, recovery, pediatric, and general medicine bed occupancy levels.
- **Outpatient Consultations**: Specialist doctor appointment scheduling and tracking.
- **Medical Staff Duty Roster**: Multi-shift roster management with on-call emergency status badges.
- **Itemized Treatment Ledger**: Procedural billing and fee settlement tracking.
- **Occupancy & Operational Analytics**: Hospital bed capacity and emergency triage velocity metrics.

## Getting Started
```bash
npm install
npm run dev
```
